# Autoeletric

Site de uma loja virtual fictícia de veículos autopropelidos elétricos e acessórios, com compra online e retirada presencial em Curitiba/PR.

**Funcionalidades:** catálogo com busca e filtro por categoria, carrinho com limite de estoque, formulário de contato com validação, tabela de regras de circulação (CONTRAN 996/2023 e CETRAN-PR 106/2026), vídeo e áudio na página Sobre.

**Tecnologias:** HTML5, CSS3, JavaScript e Bootstrap 5.3 (arquivo local em `css/`). O carrinho fica no `localStorage` do navegador, sem servidor.

**Como usar:** abra o `index.html` no navegador. A documentação está na pasta `doc/`.
